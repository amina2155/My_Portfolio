Android Application

Multicare Indigo

An Android emergency assistance app focused on rapid SOS communication and location sharing. The project explores a simple way to connect people in danger with trusted family and friends when professional emergency services may not be able to reach them quickly.

Tech Stack: Java, Gradle, Firebase, Google Maps API
  • Developed the SOS trigger and emergency messaging features using Java in Android Studio.
  • Integrated Firebase for user and emergency-contact data management.
  • Implemented real-time location tracking and sharing using the Google Maps API.
  • Designed the system around a single-action SOS workflow for quick emergency communication.

Educational Platform

Tech Stack: HTML, CSS, JavaScript, Firebase, GitHub

  • Implemented automatic HTML/CSS code generation based on the user's visual arrangement.
